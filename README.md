# All Tiled Up — Privacy & ads

Public site for All Tiled Up (Android / Play):

- Privacy policy: site root (`index.html`)
- `app-ads.txt` for AdMob app verification (served at `/app-ads.txt`)

**Play Console → Store listing → Website** should be set to:

`https://alexrgn.github.io/AllTiledUpPrivacyPolicy/`

GitHub Pages is enabled from the `main` branch (root).
